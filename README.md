# PetFeed – сервис учета кормления животных

## Назначение
PetFeed – приложение для учета кормления животных в приюте, питомнике или
зоопарке. Оно помогает сотруднику понять, сколько корма животное уже
получило за день, сколько осталось до суточной нормы и можно ли дать
очередную порцию.

## Целевая аудитория
Сотрудники и волонтеры приютов для животных, ветеринарные клиники с
передержкой, владельцы нескольких домашних питомцев.

## Предметная область
Каждое животное имеет суточную норму корма (в граммах). В течение дня
сотрудники записывают кормления. Перекармливать животное нельзя: сумма
порций за день не должна превышать суточную норму.

## Основные сущности
- животное (кличка, вид, суточная норма корма);
- сотрудник, который кормит животное;
- кормление (животное, дата, тип корма, размер порции).

## Основные функции
- расчет остатка суточной нормы животного;
- проверка, допустима ли порция с учетом уже выданного корма;
- формирование текстового статуса кормления;
- вывод карточки животного.

## План развития
На следующих этапах планируется:
