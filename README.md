# PetFeed – сервис учета кормления животных

Консольное приложение для учета животных и их кормления.

## Возможности
- просмотр, поиск, сортировка и отбор животных;
- проверка порции по суточной норме;
- проверка возможности кормления на дату;
- запись и отмена кормлений;
- добавление животных;
- хранение данных в JSON между запусками.

## Правило предметной области
За одну дату животное не может получить корма больше суточной нормы.
Порция, из-за которой сумма за день превысит норму, не записывается.

## Структура проекта
- main.py – точка запуска и меню;
- animals.py – функции работы с животными;
- feedings.py – функции работы с кормлениями;
- storage.py – загрузка и сохранение JSON;
- utils.py – безопасный ввод чисел и дат;
- data/ – animals.json, feedings.json;
- tests/ – автоматизированные тесты pytest.

## Формат данных
animals.json: `id`, `name`, `species`, `daily_norm` (г в сутки).
feedings.json: `id`, `animal_id`, `feeding_date` (ГГГГ-ММ-ДД), `food`,
`amount` (г). Данные в программе: животные – `dict[int, dict]`,
кормления – `list[dict]`.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей: `pip install -r requirements.txt`

## Запуск программы
`python main.py`

`pytest -v`
