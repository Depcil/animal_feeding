# PetFeed – сервис учета кормления животных

Учебное приложение для учета кормления животных в приюте или питомнике.
Показывает суточную норму корма каждого животного, историю кормлений и
сколько корма еще можно дать сегодня.

Основное правило: сумма кормлений животного за день не может превышать его
суточную норму. Отмененное кормление в норму не входит.

## Технологии
Python 3, Django 5.2, SQLite, HTML, CSS, Bootstrap 5, pytest, flake8.

## Сущности
- **Животное** – кличка, вид, суточная норма корма (г);
- **Сотрудник** – имя, email;
- **Кормление** – животное, сотрудник, дата, корм, порция (г), отметка об отмене.

## Структура
```text
animals/, feedings/, homepage/   Django-приложения (views, urls, шаблоны)
templates/                       базовый шаблон, навигация, страница 404
models/                          классы Animal, User, Feeding
db/                              подключение к SQLite и импорт из JSON
sql/                             схема базы и SQL-запросы
data/                            JSON-файлы и база petfeed.sqlite
tests/                           тесты pytest
main.py                          консольная версия
```

## Запуск
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```
Сайт откроется по адресу http://127.0.0.1:8000/.
Консольная версия: `python main.py`.

База `data/petfeed.sqlite` уже лежит в репозитории. Пересоздать ее из JSON:
`python -m db.import_json`.

## Страницы
- главная;
- список животных с поиском и карточка животного;
- «Кого можно покормить» на выбранную дату;
- журнал кормлений с фильтром и страницами;
- статистика.

## База данных
Три таблицы: `animals`, `users`, `feedings`. Таблица `feedings` связана с
`animals` и `users` внешними ключами. Схема – в `sql/schema.sql`,
запросы (выборка, JOIN, агрегатные функции, GROUP BY, HAVING) – в
`sql/queries.sql`.
