# PetFeed – сервис учета кормления животных

## Назначение
PetFeed – приложение для учета животных и их кормления. Консольная версия
(ПР3) дополнена веб-интерфейсом на Django (ПР5).
Приложение позволяет:

* просматривать животных и кормления в браузере;
* просматривать карточку животного и остаток суточной нормы на сегодня;
* просматривать информацию о конкретном кормлении;
* просматривать, искать, сортировать и отбирать животных;
* проверять порцию по суточной норме животного;
* проверять возможность кормления на дату;
* записывать и отменять кормления;
* добавлять животных и сотрудников;
* хранить данные между запусками.

## Целевая аудитория
Сотрудники и волонтеры приютов, питомников и зоопарков.

## Предметная область
Основные объекты: животное, сотрудник, кормление. Сотрудник записывает
кормление животного. Сумма активных кормлений животного за дату не может
превышать его суточную норму. Отмененное кормление не учитывается и
освобождает норму; запись при этом не удаляется.

## Основные сущности
### Animal – животное
Атрибуты: `id`, `name`, `species`, `daily_norm` (г/сутки).
Методы: `fits_daily_norm()`, `validate_norm()` (@staticmethod),
`info` (@property), `__str__()`.

### User – сотрудник
Атрибуты: `id`, `name`, `email`.
Методы: `from_data()` (@classmethod), `__str__()`.

### Feeding – кормление
Атрибуты: `id`, `animal` (объект Animal), `feeding_date`, `user`
(объект User), `food`, `amount` (г), `is_cancelled`.
Методы: `cancel()`, `__str__()`.

Feeding хранит ссылки на объекты, поэтому доступны
`feeding.animal.name`, `feeding.animal.daily_norm`, `feeding.user.name`.

## Хранение данных
`data/animals.json`, `data/users.json`, `data/feedings.json`.
В `feedings.json` связи хранятся идентификаторами `animal_id` и
`user_id`. При загрузке функции `storage.py` восстанавливают объекты и
ссылки, при сохранении – обратно преобразуют объекты в данные JSON.

## Используемые технологии
* Python 3;
* Django 5.2 – веб-фреймворк;
* HTML – разметка страниц;
* CSS и Bootstrap 5.3 (через CDN) – оформление;
* pytest, flake8.

## Страницы веб-интерфейса
* `/` – главная: описание и навигация (`index()`);
* `/animals/` – список животных из `data/animals.json` (`animals()`);
* `/animals/<int:animal_id>/` – карточка животного, остаток нормы на
  сегодня (`animal_detail()`);
* `/feedings/` – список кормлений (`feedings()`);
* `/feedings/<int:feeding_id>/` – страница кормления
  (`feeding_detail()`).

Если животное или кормление не найдено, возвращается страница с кодом 404.
Для неизвестных адресов используется `handler404`
(`homepage.views.page_not_found`).

## Основные операции
Используется в вебе (ПР5): просмотр животных и кормлений, расчет остатка
суточной нормы на текущую дату.
Отложено (нужны формы и POST): добавление животных и сотрудников, запись и
отмена кормлений, поиск, фильтрация, сортировка.

## Хранение данных
JSON-файлы `data/animals.json`, `data/users.json`, `data/feedings.json`.
При загрузке данные преобразуются в объекты Animal, User, Feeding;
в `feedings.json` связи хранятся идентификаторами `animal_id`, `user_id`.

## Назначение модулей
* `petfeed/` – настройки Django и маршрутизация верхнего уровня;
* `homepage/` – функция `page()` (общий HTML-каркас) и главная страница;
* `animals/`, `feedings/` – view-функции и маршруты разделов;
* `models/` – классы предметной области (не Django-модели);
* `storage.py` – загрузка и сохранение JSON;
* `main.py`, `utils.py` – консольная версия (сохранена).

## Запуск
Веб-версия: `python manage.py runserver`, затем http://127.0.0.1:8000/
Консольная версия: `python main.py`
